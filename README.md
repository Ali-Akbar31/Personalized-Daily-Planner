# 📅 Personalized Daily Planner

A web-based intelligent daily planner that helps users manage tasks efficiently using Machine Learning. This project was developed as a final year project under the supervision of **Ms. Asma Batool** at Virtual University of Pakistan.

## 🚀 Features

### 👤 User Features
- **Secure Authentication**: User registration and login (Email/Password).
- **Task Management (CRUD)**: Create, Read, Update, and Delete tasks with deadlines, priorities, and categories (Study, Work, Health, Personal).
- **Smart Scheduling**: ML-powered suggestions for optimal task ordering based on past behavior.
- **Recurring Task Detection**: Auto-detects and suggests recurring tasks using frequency analysis.
- **Search & Filter**: Quickly find tasks by keyword, category, date, or priority.
- **Reminders**: In-app and email reminders for upcoming deadlines.
- **Productivity Insights**: Beautiful charts and graphs showing time spent per category and weekly trends.
- **Templates**: Save daily routines as templates for quick reuse.

### 🛡️ Admin Features
- **Admin Dashboard**: View system usage stats, active users, and ML performance.
- **User Management**: Approve, disable, or delete user accounts.
- **System Logs**: Monitor user activity and system events.

## 🛠️ Tech Stack

- **Frontend**: HTML, CSS, JavaScript (with responsive design)
- **Backend**: Python (Flask)
- **Database**: SQLite (Development) / PostgreSQL (Production)
- **Machine Learning**: scikit-learn, pandas, matplotlib (for visualizations)
- **Deployment**: Ready for Heroku / PythonAnywhere
